# Contributing

Contributions to the SQE Gradebook project are welcome.

Create a separate branch for your changes.
Write clear and meaningful commit messages.
Test your changes before creating a pull request.
Keep the code clean and easy to understand.
# Contributing

The project will use a simple branching strategy to keep development organized. The `main` branch will contain stable code, while new features and changes will be developed in separate feature branches. Each completed change will be reviewed and tested before being merged into `main`. Branch names should clearly describe the purpose of the change.
