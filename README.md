# SQE Gradebook

SQE Gradebook is a simple Python-based project for managing student information and scores. The project is being developed as part of Software Quality Engineering (SQE) lab work and will gradually include requirements, testing, quality practices, and continuous integration.

## Installation

1. Clone the repository:

   ```bash
   git clone <repository-url>
   ```

2. Open the project directory:

   ```bash
   cd sqe-gradebook
   ```

3. Make sure Python is installed on your system.
